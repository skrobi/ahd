# F1.3 Wymiana słowników przez Excel

- **Status:** zrobione
- **Moduł:** MasterData
- **Zależy od:** F1.1, F0.7
- **Otwarte kwestie:** –

## Cel

Pobranie słownika do Excela i wczytanie zmian z podglądem różnic.

## Wymagania

- Eksport: jeden arkusz, nagłówki = nazwy kolumn, klucze jako tekst.
- Import: kolumny rozpoznawane po nagłówkach (bez rozróżniania wielkości liter i spacji), brakująca kolumna wymagana = ERROR.
- Numer zapisany w Excelu jako liczba uzupełniany zerami do długości klucza (Cost Category).
- Podgląd różnic względem bieżącego stanu: +nowe / ~zmienione / −usunięte (brak w pliku), z problemami walidacji.
- Ta sama walidacja co przy zapisie w aplikacji; plik z ERROR nie zostaje zapisany; zatwierdzenie zapisuje wszystkie zmiany naraz.

## Poza zakresem

- wiele słowników w jednym pliku (F4.3)

## Kryteria akceptacji

- [x] Test: eksport → import bez zmian = brak różnic.
- [x] Test: zmiana, dodanie i usunięcie wiersza w pliku dają +1/~1/−1.
- [x] Test: plik z błędem nie zmienia słownika.
