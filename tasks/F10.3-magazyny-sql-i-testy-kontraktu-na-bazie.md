# F10.3 Magazyny SQL i testy kontraktu na bazie

- **Status:** w toku (zrobione: import, administracja, słowniki globalne, dziennik, problemy)
- **Moduł:** całość
- **Zależy od:** F10.2
- **Otwarte kwestie:** –

## Cel

Przełączenie aplikacji na bazę bez zmian w modułach.

## Wymagania

- `Sql*Store` (Dapper, SqlBulkCopy); te same testy kontraktu co dla wersji w pamięci; `DataMode=Sql`.

## Kryteria akceptacji

- [x] Testy magazynów (import, administracja, słowniki, migracje) przechodzą na SQL Server 2022 (`PZLEV_TEST_SQL`).
- [ ] Te same testy na bazie TEST (`PZLTEST`) i ręczny test aplikacji na `PZLTEST.FINOP`.
