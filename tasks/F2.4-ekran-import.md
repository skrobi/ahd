# F2.4 Ekran Import

- **Status:** zrobione – scenariusz do sprawdzenia na stanowisku (Windows)
- **Moduł:** Import
- **Zależy od:** F2.2, F2.3, F0.8
- **Otwarte kwestie:** –

## Cel

Analityk uruchamia import i widzi, co się stało z każdym plikiem.

## Wymagania

- **Importuj** – wszystkie aktywne lokalizacje i folder `Do_importu`; postęp, anulowanie.
- Wynik: decyzja dla każdego pliku, liczba wierszy, problemy, sumy kontrolne.
- Historia importów: kto, kiedy, liczniki – widoczna dla wszystkich; szczegóły wybranej partii.
- **Sprawdź źródła** (bez importu): dostęp do lokalizacji, ścieżka czytana, pliki, podfoldery, rozpoznanie pliku;
  szczegóły importu i sprawdzenia w logu aplikacji.
- **Importuj** = logowanie do SharePoint (brama F5, jak Office – MS-OFBA) → lista plików pasujących do definicji
  z datami („zostanie zaimportowany”) → import ze zmianą statusu każdego pliku; **Sprawdź źródła** – bez importu.
- Tylko jedna osoba naraz (blokada wspólna); wpis „w toku” w historii od początku importu; druga osoba widzi, kto
  importuje i od kiedy.
