# F0.3 Konfiguracja aplikacji

- **Status:** zrobione
- **Moduł:** Shell
- **Zależy od:** F0.1
- **Otwarte kwestie:** –

## Cel

Ustawienia środowiska w jednym pliku obok exe – bez zmiany kodu między TEST i PROD.

## Wymagania

- Plik `pzl-ev.json` obok `PZL-EV.exe` (opcjonalny – brak = wartości domyślne): `Environment`, `NetworkRoot` (korzeń folderów środowiska), `DataMode` (`InMemory` | `Sql`), `InMemoryStatePath`, `ConnectionString`.
- Wartości domyślne: `TEST`, `NetworkRoot` = `%LOCALAPPDATA%\PZL-EV\TEST-root`, `InMemory`, stan w `%LOCALAPPDATA%\PZL-EV\inmemory-state.json`.
- Błąd w pliku konfiguracji = czytelny komunikat przy starcie; `DataMode=Sql` przed F10 = komunikat „tryb niedostępny”.
- Środowisko i tryb danych widoczne w nagłówku i w Diagnostyce.

## Poza zakresem

- edycja konfiguracji w aplikacji
- szyfrowanie connection string (Windows Authentication – brak haseł)

## Kryteria akceptacji

- [x] Aplikacja startuje bez pliku konfiguracji.
- [x] Zmiana `NetworkRoot` w pliku zmienia folder importu.
