# F2.3 Parser ACTUALS_* → dane kanoniczne

- **Status:** zrobione
- **Moduł:** Import
- **Zależy od:** F2.2
- **Otwarte kwestie:** O27, O7

## Cel

Wiersze surowe kosztów rzeczywistych zamienione na dane typowane według definicji źródła.

## Wymagania

- Sygnatura kolumn pliku zgodna z definicją; niezgodna = ERROR dla wersji pliku, dane kanoniczne nie powstają.
- Kolumny typowane (`can.Actuals`): projekt CES, element WBS, element kosztowy (numer liczbowy uzupełniany zerami do 10 znaków), opisy, waluty, kwoty (decimal), ilość, rok, data utworzenia, okres; wersja pliku i wersja parsera.
- Wartość niezgodna z typem = ERROR z numerem wiersza i kolumną; plik z błędem typu nie tworzy danych kanonicznych.
- Duplikaty klucza – gdy definicja ma kolumny klucza (dla `ACTUALS_*` klucz do ustalenia – O27).
- **Weryfikacja przepływu:** liczba wierszy i suma kwot danych kanonicznych = wiersze surowe (zapis w dzienniku importu).

## Poza zakresem

- ponowne przetworzenie nowym parserem (później)
