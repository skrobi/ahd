# F4.2 Nakładka Performance Objectives

- **Status:** zrobione
- **Moduł:** Projects
- **Zależy od:** F4.1, F3.2
- **Otwarte kwestie:** O46

## Cel

Struktura kontraktu CES wyznaczająca zakres projektu.

## Wymagania

- Import Excela (układ rozdz. 5), drzewo wg Level, węzły wirtualne, edycja i przeciąganie, historia; strona P1S przez mapowanie.

## Kryteria akceptacji

- [x] Test: Excel wzorcowy → drzewo o oczekiwanej strukturze (`ObjectivesTests`, `app/testdata/Projekty/PO_M28.xlsx`).

## Realizacja

- O46: element CES w co najwyżej jednej nakładce – ERROR z kodem projektu.
- Strona P1S z globalnego mapowania (F3): status i cel elementu CES, poddrzewo celu z LOG.WBS; obok `Legacy WBS`
  z Excela. Rozstrzyganie mapowania przeniesione do `Shared/Utils/Mapping` (moduły Mapowanie i Projekty).
- O47 rozstrzygnięte w F4.6: po utworzeniu projektu eksport SAP tylko dokłada nowe elementy (węzły wirtualne
  i zmiany w aplikacji zostają); odświeżenie zastępujące strukturę usunięte.
- Kolumny opisowe eksportu SAP (`Applicant`, `Costing Sheet`, …) nie są zapisywane – tabela `META_PerformanceObjective`
  nie ma na nie kolumn.
