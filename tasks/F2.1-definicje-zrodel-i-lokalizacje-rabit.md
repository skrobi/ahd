# F2.1 Definicje źródeł i lokalizacje RABIT

- **Status:** zrobione
- **Moduł:** Administration / Import
- **Zależy od:** F0.4, F0.5
- **Otwarte kwestie:** O27

## Cel

Import wie, jakie pliki rozpoznaje i skąd je pobiera – konfiguracja w danych, nie w kodzie.

## Wymagania

- Definicja źródła (`meta.SourceDefinition`, historia techniczna): kod, prefiks, typ raportu, oczekiwane kolumny (→ sygnatura), ziarno, kolumny klucza, znaczenie kolumn i okresu, waluta, format liczb, wersja parsera, aktywna.
- Prefiks unikalny (bez rozróżniania wielkości liter); każdy prefiks to osobne źródło.
- Lokalizacje RABIT (`meta.SourceLocation`): nazwa, ścieżka (UNC / WebDAV / folder), aktywna.
- Dane startowe: `ACTUALS_PAF`, `ACTUALS_CES` (układ `docs/zrodla-danych.md` rozdz. 4); lokalizacja `E456659` (nieaktywna w trybie w pamięci).
- Ekran Administracja: definicje źródeł i lokalizacje – dodanie, zmiana, dezaktywacja.
